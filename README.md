# Rock-paper-scissor-game
A simple and interactive Rock Paper Scissors Game built using HTML, CSS, and JavaScript. Play against the computer, test your luck, and see who wins!

# About the Project

This project is a browser-based Rock Paper Scissors game where the user plays against the computer. The computer randomly selects Rock, Paper, or Scissors, and the winner is decided according to the game rules.

This project was created to practice JavaScript fundamentals, DOM manipulation, event handling, and basic game logic.


# Game Rules

Rock beats Scissors.

Scissors beats Paper.

Paper beats Rock.

If both players choose the same option, the result is a draw.


# Features

Interactive Rock, Paper, and Scissors choices.

Computer generates random choices.

Automatic winner detection.

Real-time score updates.

Displays game result messages.
